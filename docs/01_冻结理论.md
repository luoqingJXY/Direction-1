# 最终目标的理论确认

本文只保存用户已经确认或旧对话已经闭合的内容。错误解释、撤销方案、反例、未经确认的实验参数和助手自行提出的名称不进入本文。

## 1：本项目所遵守的准则

所有概念在本项目中都有其特定的解释，不按照其他理论运行，禁止搬其他算法理论结构进来。

## 2. 已闭合的整体理论

### 2.1 ArtificialLife

- World、身体、器官、Brain、Memory Cache、Sleep、Teaching 和 Console 在工程上可以拆分，运行逻辑仍属于同一个 ArtificialLife。
- 个体形成发生在完整生命回环中，不把组件分别形成后再拼成个体。
- Runtime 维持生命状态连续变化，不是传统训练循环。
- ArtificialLife 能实际容纳的整体 Brain 结构、活动状态和运行规模，受硬盘、系统内存、显存、CPU 与 GPU 联合形成的物理容量限制。

### 2.2 Signal（本质信息流，抽象概念为思维）

- Signal 强度表示正在发生的生命活动，不表示其他。
- 每一项器官输入活动先独立进入一个固定接收神经元；进入时不复制、不平均，也不与其他器官活动预先合并。
- 每个固定接收神经元再通过一条一对一固定路径，把该项活动送入唯一对应的普通神经元；固定接收神经元承担不变的器官接触关系，普通神经元进入后续可塑组织。若人工出生结构还需要从该项输入形成其他先天通道，分支只能发生在活动已经进入 Brain 以后。
- 进入 Brain 的 Signal 不携带实体 ID、目标实体、词义标签、答案或任务标签。
- 窗口、网络、安全和日志状态不属于生命 Signal。

### 2.3 视觉输入

- 路径为：真实捕捉画面 → 用视野中心概念扭曲缩小 → 视觉感受场/受体 → Visual Signal → Brain。
- 每个已经选定的视觉位置只形成 R、G、B 三个活动，并全部直接进入 Brain。
- 画面输入阶段不额外形成 field_activity、change_activity，也不先做亮度、边缘或前后帧比较。
- 画面输入形成活动，不形成实体列表、直接坐标或识别结果。
- 视觉分辨率只决定第二次实验中视觉器官包含多少个位置，不改变视觉活动的性质和完整生命回环的运行关系；第二次实验采用 1280×657 个视觉位置。
- 视野中心空间变换保持 1280×657 不变。输出位置在视野中心两侧分别归一化，按照距离的平方映射回真实画面；中心、四边和四角保持对应，中心附近使用更多位置，外围使用更少位置。映射到非整数位置时取最近的原始位置，直接取得该位置的 R、G、B，不平均相邻位置。
- 去低频在空间变换之后进行，R、G、B 三个平面分别进行二维傅里叶变换，互不混合。频率半径不大于 \(1/256\) 的部分归零；从 \(1/256\) 到 \(1/128\) 线性增加到完整保留；不小于 \(1/128\) 的部分完整保留。遮罩只由频率位置决定，不根据画面内容改变。
- 去低频反变换后的每个平面用固定关系 \(\operatorname{clip}_{[0,1]}(0.5+p/2)\) 形成非负强度，再转成 8 位活动。不得按每份画面的最大值、最小值或平均值重新归一化；最终每个视觉位置仍然只有 R、G、B 三个活动。

### 2.4 听觉输入

- 第二次实验接收三份彼此独立的声音活动：电脑左声道、电脑右声道和麦克风声道。不同声音流可以异步发生，不要求彼此同步。
- 声音器官以每秒 48,000 个原始取样工作。每收到 192 个新取样形成一次新的听觉活动；器官内部使用最近 2,048 个取样的固定窗口形成 1,025 个频率位置。取样数量和窗口只属于客观器官处理，不作为时间数值进入 Brain。
- 每个频率位置的固定二维声音响应记为 (x,y)，令 (r=\sqrt{x^2+y^2})，形成三个非负活动：(a_0=r\)、(a_1=(r+x)/2\)、(a_2=(r+y)/2\)。器官采用固定归一化关系保证三者处于 ([0,1])；无声时三者均为零。Brain 不接收 (x,y) 或正负方向标签，只接收三个客观受体活动。
- 三个非负活动保存完整二维响应关系，声音器官能够按 (x=2a_1-a_0\)、(y=2a_2-a_0) 还原；负数只可能出现在器官内部还原过程中，不进入 Brain 的 Signal。
- 听觉器官不保存额外的历史位置。连续声音活动反复进入同一组固定受体，发生顺序由 Memory Cache、Neuron 持续活动和 Path 传播共同承载。
- 第二次实验听觉活动总数为 (3\times1025\times3=9,225)。每一项听觉活动遵守固定接收神经元、一对一固定路径和对应普通神经元的统一入口关系。
- 预测听觉器官输出 (3\times342\times85\times3=261,630) 个非负活动。85 个位置表示预测器官当前输出的一段发生顺序排列，不保存已经发生的声音，也不携带时间数值。

### 2.5 运动器官

- 视野中心也由一个运动器官控制。
- 预测器官本质也是运动器官。图像预测器官的输出大小为（512×512）的灰度[0,1]图像；预测听觉器官的输出为已经确认的 261,630 个非负活动。
- 声音器官本质也是一个运动器官，只是有更多的输出和参数。
- 运动器官定义为接收信号并实际做出动作，动作根据信号强弱天然具有“幅度”。
- Teaching 接管实际鼠标和键盘器官时，Brain 自己形成的动作倾向仍被保存。

### 2.6 Neuron、Path、Region

- Neuron 具有持续活动、阈值和调制；一次没有越过阈值不代表活动立即消失。
- Neuron 具有由人工DNA确定的活动响应强度；活动响应强度可以大于 `1`，因此放大发生在 Neuron，不发生在 Path。
- 同一个 Neuron 实际接收到的多路普通活动直接相加。
- 可塑路径削到零时不再削弱，此时路径等于消失，所以依照这个机制，所有神经元在底层结构中，与所有相邻神经元相连。
- Path 是传播关系，不是标量权重。
- 所有符合连接和传播条件的 Path 都参与传播，不选择赢家或最佳路径。
- 信号流过时，会根据路径本身强度进行削弱，路径越强，信号削弱得越少。
- 固定路径由出生结构决定；可塑路径会在信号流过时根据情绪器官所控制的“物质值”进行相应的增强。
- 如果“物质值”高过某条相邻可塑路径的形成阈值，实际有信号流入的普通神经元会在人工DNA允许形成的区域空间中增强朝向直接相邻普通神经元的零强度路径。形成强度由来源神经元实际收到的路径活动、该路径的物质受体响应、形成阈值和路径变化系数共同决定。
- 在第二次实验的 `800×800×160` 三维神经组织（共 `102,400,000` 个神经元位置）中，一个神经元周围坐标差各不超过 `1`、且不与自身重合的 `26` 个位置定义为直接相邻。零强度可塑路径只存在于这些直接相邻位置之间；跨组织和跨区域的先天传播由出生结构中的固定路径形成。
- Region 是神经组织，不是传统前馈网络的层。
- Brain 中可观察的机制表现、能力和行为，均由神经元、路径、组织、区域及器官在完整生命回环中的联合作用形成，不能归因于单个神经元、单条路径或单一区域。

### 2.7 Emotion Organ

- 画面、声音、动作或身体状态先形成神经活动，活动会沿人工DNA制定的特殊短Path到达 Emotion Organ 的控制入口。
- Emotion Organ 的每个控制入口保持为一项独立的连续物质活动；多个特殊短 Path 到达同一控制入口时直接相加，不预先压成正面、负面、满足、不安或其他含义标签。第二次实验当前生命状态本能的 `70` 个控制入口形成 `70` 项彼此独立的连续物质活动。
- Emotion Organ 返回的连续调制活动不能直接改变 Neuron 当前状态。人工DNA为具体 Neuron 的活动响应强度和阈值、以及具体 Plastic Path 的物质受体响应和变化系数规定调制关系；同一项物质活动可以因出生受体关系不同而使不同属性产生不同方向和程度的当前有效变化。
- Emotion 不选择正确 Path，也不是奖励、惩罚或好坏评分。
- 某个行为、画面或音频如何激活 Emotion Organ，是反复实验一点一点更改人工DNA优化的。

### 2.8 Artificial DNA

- DNA 描述出生结构：Region 组织、Neuron 局部形态、Fixed Path、器官连接、调制受体分布、Plastic Path 形成空间，能调整某条具体Path的属性。
- 每项器官活动进入对应普通神经元后，必须先由独立的继续通道保留其内部差异；人工DNA不得在没有明确汇合结构、阈值和后续展开关系时，按轮流分配、最近位置缩并、顺序编号配对或编号取余把多项不同活动提前混入同一神经元。
- 人工DNA中的微观通道由独立继续、分支、多路汇合、跨组织返回、预测还原和器官输出等实际 Neuron 与 Path 分节组成。这些只是连接结构的不同排列，不是新增运行机制。大规模程序生成只能机械展开已经确定的分节排列，不能随机替人工DNA发明连接。
- 器官应当在本项目中是客观存在。
- DNA 出生后保持不变；经历改变个体的 Plastic Path 状态。
- DNA 不保存人格名称、行为策略、语言答案或后天记忆。
- 人格为 Emotion Organ 所连接的先天结构和后天 Path 之间的复杂干涉关系。

### 2.9 Memory Cache

- 具体实现时 Memory Cache 只是栈，因不同输入要从 Brain 的不同入口进入，时间概念在项目中抽象为事物的发生顺序，所以 Memory Cache 只是一个容纳所有输入的容器，再根据不同的信息流把相应的信息流传往相应的 Brain 入口。不同信息流的发送可以异步，要做到一直实时发送的效果，不同的信息流之间不用同步。
- 一个 TimeFrame 保存预测的画面、预测的音频、外部采集到的画面、外部采集到的音频、实时产生的动作信号（不管有激活运动还是没激活）。
- Brain 一直获取信息流，时间不存在于 Brain 中，时间被抽象为事物发生顺序。
- Action 保存 Brain 的动作倾向，Teaching 时同样。
- 同一客观来源的一次完整活动作为一项完整发生发送；一幅视觉的 R、G、B 和完整受体状态不能因网络分段或程序数组顺序被拆成多个脑内发生。不同异步信息流可以连续到达，但两项完整发生不能在同一次状态变化尚未完成时彼此穿插。
- 一项完整发生在 Brain 内造成的多路直接到达必须先按目标 Neuron 直接相加，再统一提交该 Neuron 的下一状态。当前发生内部产生的预测、动作回流或下一段传播只能排在当前完整状态之后，不能递归插入当前状态变化中间。

### 2.10 Sleep、Teaching、Console

- Sleep 启动时会对所有路径进行少量削弱，除了固定路径。
- Sleep 对 Plastic Path 采用固定小量的减法削弱并限制在不低于零，使路径能够实际削到零；不得使用永远无法到达零的比例乘法。固定小量的具体实验数值在个体出生前确定。
- Sleep 本质就是关机功能，没有除了削弱路径之外的其他机制，顺序是先削弱路径、关闭 Memory Cache 的发送、储存 Path、全部关闭。
- 重新启动时，直接读取关机前保存的人工生命结构和路径状态，继续原有个体的生命过程。
- Teaching 只暂时接管鼠标和键盘器官。
- Console 只观察并启动或停止 Teaching、Sleep，不能设置目标、奖励或结构。

注意：项目中全部信息流都不用“根据时间”，时间只存在于事物的发生顺序中，也不用记录。

神经元也分固定神经元和普通神经元，与路径相同。固定神经元的属性不会改变；固定路径不会增强。涉及固定神经元的直接相邻连接保持固定，不能因物质活动形成或增强。普通神经元即使连接了一条固定路径，其自身以及与其他普通神经元之间的可塑关系仍按可塑路径规则变化。

## 全部大脑的输出器官

- Brain 内的末端 Neuron 不能直接冒充器官输出。每项输出必须沿固定 Path 到达客观输出器官自己的控制入口，所有到达同一入口的 Path 当前活动直接相加形成该项输出倾向。
- 在声音器官数量尚未补充前，第二次实验已经确定形状的预测视觉、预测听觉、鼠标、键盘和视野中心共有 `523,890` 个控制入口，对应 `523,890` 条末端固定输出 Path。

- 预测视觉：产生预测的视觉。
- 预测听觉：产生预测的听觉。
- 情绪：能控制“物质值”，物质值影响路径的强化；过高的物质值会使信号流过的路径的神经元产生新的朝向相邻神经元的路径。固定路径本身以及固定神经元的属性和相连连接不因此改变；普通神经元即使连接了固定路径，其其他可塑路径仍然可以形成或增强。
- 鼠标运动：产生 X、Y 和 -X、-Y 的信号，信号强度对应其运动的速度，有阈值。
- 键盘运动：产生108种信号，信号强度超过阈值则“按下”，按下状态时信号低于阈值则“松开”。
- 声音：产生（元音/辅音数量）的信号，具体待补充。
- 视野中心控制：跟鼠标的控制逻辑一样。

## 3. 全项目统一公式

以下公式是本项目解释全部结构、机制表现、能力和行为的统一约束。局部神经元和路径关系只能作为其中的基础操作，不能脱离完整生命回环单独解释任何能力。

人工DNA记为 \(D\)，出生后保持不变。人工生命在某个实际发生顺序位置上的完整当前状态记为：

\[
\mathcal L=(W,B,C,U,A,Q,P,M,Y,R)
\]

- \(W\)：World 当前状态；
- \(B\)：身体当前状态；
- \(C\)：Memory Cache 当前容纳和发送状态；
- \(U\)：全部器官当前输入活动；
- \(A\)：全部 Neuron 当前活动；
- \(Q\)：全部 Path 当前正在传播的活动；
- \(P\)：全部 Fixed Path 与 Plastic Path 的结构和后天状态；
- \(M\)：Emotion Organ 当前调制活动和物质值；
- \(Y\)：全部预测和运动器官当前输出倾向及实际输出；
- \(R\)：Runtime、Teaching 与 Sleep 当前运行状态。

下一次真实的外部或内部信息发生记为 \(\varepsilon\)。它只表示实际发生的下一项变化，不携带时间数值、目标、答案或任务标签。完整生命状态变化统一写为：

\[
\boxed{
\mathcal L^{+}=\Phi_D(\mathcal L,\varepsilon)
\qquad
\mathbf R_{\mathrm{资源}}(\mathcal L^{+})\leq\mathbf B_{\mathrm{物理}}
}
\]

上标 \(+\) 只表示事物发生顺序中的下一个完整状态，不是 Brain 中的时间、时钟或训练轮次。不同信息流继续异步到达；Runtime 只更新实际受到本次发生影响的状态，不要求全部信息流同步。

同一完整发生采用“读取旧完整状态、形成全部直接结果、一次提交下一完整状态”的关系。程序线程顺序、数组顺序、网络分段顺序以及 CPU/GPU 的并行次序不能改变结果。某次传播读取本次发生前的 Path 强度；本次发生形成的 Path 新强度只能影响以后发生的传播，不能倒过来重算刚完成的传播。

统一变化关系展开为：

\[
\begin{aligned}
\Pi^{\mathrm{有效}}&=\mathcal G_D(\Pi,M) \\
S_i&=U_i+\sum_{e:\,t(e)=i}Q_e \\
A^{+}&=\mathcal N_D(A,S,\Pi_N^{\mathrm{有效}}) \\
Q_e^{+}&=\mathcal H_{D,e}\!\left(A^{+}_{s(e)},P_e,\theta^{\mathrm{有效}}_{s(e)},\Pi_e^{\mathrm{有效}}\right) \\
M^{+}&=\mathcal E_D\!\left(\sum_{e:\,t(e)=\mathrm{Emotion}}Q_e^{+}\right) \\
P^{+}&=\mathcal K_D(P,Q^{+},M^{+},R) \\
Y^{\mathrm{Brain}}&=\mathcal O_D(Q^{+}) \\
Y^{\mathrm{实际}}&=\mathcal T\!\left(Y^{\mathrm{Brain}},R\right) \\
(W,B)^{+}&=\mathcal W\!\left(W,B,Y^{\mathrm{实际}},\varepsilon\right) \\
(U,C,R)^{+}&=\mathcal V_D\!\left((W,B)^{+},U,C,R,Y^{\mathrm{Brain}},\varepsilon\right)
\end{aligned}
\]

已确认的微观基础关系为：

对受到当前发生影响的 Neuron \(i\)，人工DNA规定其出生活动响应强度 \(g_i\geq0\) 和阈值 \(\theta_i\geq0\)。当前物质活动只通过出生受体关系形成有效属性：

\[
g_i^{\mathrm{有效}}
=\max\!\left(0,g_i+\sum_j r^g_{ij}M_j\right)
\]

\[
\theta_i^{\mathrm{有效}}
=\max\!\left(0,\theta_i+\sum_j r^\theta_{ij}M_j\right)
\]

普通活动先直接相加，随后形成 Neuron 当前活动：

\[
S_i=U_i+\sum_{e:\,t(e)=i}Q_e,
\qquad
A_i^{+}=g_i^{\mathrm{有效}}S_i
\]

这里没有独立的旧活动保留比例。持续活动来自仍然存在的器官当前活动、Path 当前传播活动以及多 Neuron、多 Path、多区域回路；没有越过阈值只是不向后传播，不把仍然存在的当前活动清零。未受本次发生影响的 Neuron 保持其当前状态。

每条 Path 按以下关系传播：

\[
Q_e^{+}=
\begin{cases}
A_{s(e)}^{+}P_e,
& A_{s(e)}^{+}\geq\theta_{s(e)}^{\mathrm{有效}},\ P_e>0,\\
0,&\text{其他。}
\end{cases}
\]

其中 \(0\leq P_e\leq1\)。Path 强度 1 表示完整传播，越接近 0 削弱越多；Path 不放大活动。所有符合条件的 Path 同时参与传播。

Emotion Organ 的控制入口活动为：

\[
M_j^{+}=\sum_{e:\,t(e)=j}Q_e^{+}
\]

它只保留每个客观控制入口的连续物质活动，不赋予含义标签。

对已经具有非零强度、且在清醒状态下实际传播的 Plastic Path \(e\)，令：

\[
h_e=\max\!\left(0,\sum_j r^P_{ej}M_j^{+}\right)
\]

\[
P_e^{+}
=\min\!\left(1,\,
P_e+\lambda_eQ_e^{+}h_e(1-P_e)
\right)
\]

其中 \(\lambda_e\geq0\) 是人工DNA为该条具体路径规定的变化系数。没有实际传播、没有相应物质受体活动或已经达到完整强度时，不产生该项增强。Fixed Path 不进入此关系。

对人工DNA允许形成、当前强度为零的直接相邻 Plastic Path \(i\rightarrow n\)，令来源普通 Neuron 实际收到的 Path 活动为：

\[
F_i=\sum_{k:\,t(k)=i}Q_k^{+}
\]

其形成关系为：

\[
P_{i\rightarrow n}^{+}
=\min\!\left(1,\,
\lambda_{i\rightarrow n}F_i
\max\!\left(0,h_{i\rightarrow n}-\mu_{i\rightarrow n}\right)
\right)
\]

其中 \(\mu_{i\rightarrow n}\) 是该相邻关系由人工DNA规定的物质形成阈值。只有普通 Neuron、实际流入活动、物质值超过阈值和区域形成许可同时存在时，零强度路径才形成实际非零强度。

Sleep 时所有 Plastic Path 改为：

\[
P_e^{+}=\max(0,P_e-\delta_{\mathrm{睡眠}})
\]

Fixed Path 保持不变。

这些符号只是对已经存在的项目关系作统一表示，不是新增组件：

- \(\Pi\) 表示人工DNA已经允许存在的 Neuron 或 Path 响应属性；\(\mathcal G_D\) 表示调制活动只能按照DNA中的调制受体分布改变 Neuron 的当前有效活动响应强度和阈值，以及 Plastic Path 的物质受体响应，不能直接加入普通活动或改变DNA。
- \(S_i\) 是器官入口和所有实际到达 Path 当前活动的直接总和，不包含标签、选择、平均或赢家判断。
- \(\mathcal N_D\) 表示全部 Neuron 在当前完整结构中的联合状态变化；它保留当前活动状态这一事实，但不预设独立的旧活动保留比例。持续、消散和重新激活优先由多神经元、多路径和多区域联合作用解释。
- \(\mathcal H_{D,e}\) 表示 Path 的传播关系：来源活动不符合阈值或路径强度为零时不传播；符合条件的所有 Path 都传播，并按照路径自身强度削弱活动。\(Q_e\) 是当前传播活动，\(P_e\) 是路径结构和后天状态，两者不能混同。
- \(\mathcal E_D\) 表示到达 Emotion Organ 控制入口的全部特殊短Path活动共同形成其当前输出；Emotion 不判断正确、错误、好坏或目标。
- \(\mathcal K_D\) 表示路径状态变化：Fixed Path 不因经历改变；清醒状态下实际流过的 Plastic Path 按已经确认的微变关系增强，高物质值下的零强度相邻路径按来源流入活动、物质受体、形成阈值和区域许可形成；Sleep 时执行固定小量减法削弱和关机顺序。
- \(\mathcal O_D\) 表示到达各输出器官的全部活动共同形成 Brain 的预测、声音、鼠标、键盘和视野中心输出倾向。
- \(\mathcal T\) 只表示 Teaching 对实际鼠标和键盘器官的暂时接管；\(Y^{\mathrm{Brain}}\) 始终保留并进入 Action。
- \(\mathcal W\) 表示实际输出改变身体和 World，外部真实变化也在其中继续发生；预测器官输出不直接改变 World。
- \(\mathcal V_D\) 表示器官重新形成输入、Memory Cache 按既定入口异步容纳和发送信息，以及 Runtime 维持 Teaching、Sleep 和清醒状态。Memory Cache 不比较答案、不训练 Brain，也不把时间数值送入 Brain。

公式中的各关系互相依赖：Neuron 活动决定 Path 当前传播，Path 传播又共同决定其他 Neuron、Emotion Organ 和输出器官；输出改变 World 和身体后重新形成感受；Emotion Organ 改变活跃 Plastic Path 的后天状态，路径状态又改变以后所有可能经过它的跨区域传播。任何机制表现、能力或行为只能由这一完整联合关系及其连续发生顺序解释。
