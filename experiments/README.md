# 实验档案

## 第一次实验

[第一次实验](01_第一次实验/README.md)是早期小规模可运行闭环，保留了完整报告和逐项观测文件。它包含272个神经元、864条路径、世界实体运动、教学、情绪调制、预测连续性和睡眠结算记录。

这次实验形成于最终理论冻结之前，其中“回环”“清醒期痕迹”“睡眠结算”等机制已经被后续理论撤销或重写。因此它只能作为项目演进和工程观测能力的历史证据，不能作为当前理论验证结果。

## 第二次实验

[第二次实验](02_第二次实验/README.md)面向完整规模模型：双电脑、真实 Minecraft 画面与声音、真实键鼠动作、102,400,000个神经元位置、2,662,400,000个局部相邻路径槽位、人工出生结构、生命状态本能和长期个体存储。

第二次实验已经实际出生大型个体并启动过运行，但因大脑运行器错误地使用全量扫描推进路径，当前结果不能作为正式实验结果。外围代码、人工出生结构、存储清单、参考活动和故障证据均已保留。
