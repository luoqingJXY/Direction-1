# 公开源码边界

本目录保存除“大脑本体”以外可以公开审阅的现有程序。代码来自实际工程快照，不是为了展示而重新编写的伪代码。

## 已公开

- `artificial_dna`：第二次实验的人工出生结构、神经组织地址、器官入口、固定路径展开、局部可塑空间、本能结构和出生属性生成代码。
- `peripherals/host_b`：乙电脑的 Minecraft 窗口捕捉、视觉处理、听觉处理、局域网传输、键鼠动作、教学接管、虚拟麦克风安装和运行脚本。
- `life_support`：甲电脑的记忆缓存边界、器官输入/输出边界、控制台、睡眠、观察、存储和传输代码。
- `vocal_organ`：早期声音器官与声音单位生成、稳定声音输出和表达范围测量代码。
- `hardware_tools`：CPU、显卡、内存、硬盘和外围设备检测工具及硬件研究记录。

## 没有公开的大脑本体

以下内容没有上传：

- 正式神经元与路径传播运行器；
- 完整状态变化执行核心；
- 显卡全脑计算后端；
- 运行工作区和全量提交实现；
- 神经元活动、路径活动、可塑路径状态和调制受体的大型数组；
- 已出生个体的完整生命状态。

因此，公开的人工出生结构代码可以审阅其组织和连接怎样生成，但不能单独启动完整大脑。部分文件保留了对未公开大脑本体模块的引用，这是实际工程边界，不应补成另一套运行机制。

## 状态说明

现有代码处于实验开发阶段。人工出生结构已经大规模展开，但当前未公开的大脑运行器存在“全量扫描被误作传播步骤”的已知错误。代码存在不等于理论已被正确实现；理论仍以 `docs/01_冻结理论.md` 为唯一依据。
