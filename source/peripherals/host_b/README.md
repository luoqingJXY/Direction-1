# 第二次实验：乙电脑源码

本目录是乙电脑的新实现，不继承旧实验程序的理论含义。当前阶段不打包，
所有源码和配置都可以直接修改。

## 当前已经实现的源码边界

1. 集中配置和正式运行前检查。
2. 与乙电脑有关的固定连接切入点。
3. 不含时间戳和生命时间的局域网二进制帧。
4. 每种信息流使用独立局域网连接。
5. Minecraft窗口精确定位。
6. 1280×657原始RGB诊断捕捉。
7. 视觉位置无损变化编码和重建。
8. Windows声音设备发现和原始采集诊断。
9. 鼠标键盘最终执行端。
10. 教学对真实鼠标键盘执行端的接管。
11. 已形成声音波形后的真实播放端。
12. 接收教学启停和睡眠关闭控制的外围运行编排。
13. 承载鼠标、键盘、视野中心和声音实际执行端的人工身体容器。

## 当前切入点

乙电脑向甲电脑发送：

- 视觉受体变化；
- 听觉受体变化；
- 控制信息。

甲电脑向乙电脑发送：

- 鼠标活动；
- 108个键盘活动；
- 视野中心活动；
- 声音输出；
- 控制信息。

人工DNA不在乙电脑中实现。它以后只负责在甲电脑中决定这些入口和出口
怎样连接脑内区域、神经元与路径。

## 依赖顺序

1. 先编辑 `host_b.example.toml` 对应的实际配置。
2. 在乙电脑确认Minecraft窗口名称、进程名和1280×657客户区。
3. 确认画面捕捉能得到完整RGB数据。
4. 用户确认非线性空间变换和去低频规则后，接入视觉变化发送。
5. 用户确认听觉感受场排列后，接入听觉变化发送。
6. 用户确认鼠标合成规则、108键对应和视野中心方向后，启用实际动作。
7. 甲电脑接收端完成后，连接完整生命回环。

## 源码阶段命令

在 `artificial_brain_exp` 目录运行：

```powershell
python -m second_experiment.host_b 初始化配置 host_b.toml
python -m second_experiment.host_b 检查 host_b.toml
python -m second_experiment.host_b 系统
python -m second_experiment.host_b 检查窗口 host_b.toml
python -m second_experiment.host_b 声音设备
python -m second_experiment.host_b 捕捉一帧 host_b.toml
```

当前没有“正式运行”命令；直到依赖的生命信号规则确认并接入甲电脑后才添加。
